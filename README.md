# Construction Company Website

A responsive construction company website built with **HTML5, Tailwind CSS, Material Symbols, and JavaScript**.

The website showcases construction services, completed projects, company information, business partners, and contact details.

---

## 🚧 Project Overview

This website is designed for a professional construction company that provides:

- Residential Construction
- Commercial Construction
- Interior Designing
- Pre-Construction
- Civil Engineering
- Special Projects
- Site Management
- Landscape Construction

The website is designed to be fully responsive across mobile, tablet, and desktop screens.

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Material Symbols
- Google Fonts
